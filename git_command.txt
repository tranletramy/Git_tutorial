git init 			initialize project to use git
git add . 			add all changes to be saved
git add *filename* 		add single file to be saved
git commit -m "message" 	save changes with message 
git push origin master 		push changes to GitHub master
git push origin new-branch 	push changes to GitHub new-branch
git pull origin master 		pull changes from GitHub master
git checkout -b new-branch 	create a new branch
git status			check status of changes
git log				see all previous saved changes
git checkout *commit hash*	travel back to old commit

========== Configure Git for the 1st time ===============
(this is like telling Git who you are. This info is used in your commits)
git config --globle user.name "My Tran"
//git config --globle user.email "tramy200816@gmail.com"
git config --list			(list all config)

// =====================================================
git diff 				to see the differences of the files before and after updated (changes that are not added to stage)
git show HEAD~1:git_command.txt 	to see the previous version of file git_command.txt (one commit before the current one)
git rm --cached demo.log 		to ask git stop tracking file demo.log if this file was tracked before we create .gitignore file

// =============== new branches =======================
git branch 								to see all branches 
git branch cpm-analytics 						to create a new branch named cpm-analytics
git checkout cpm-analytics						to switch to cpm-analytics branch
git checkout -b cpm-analytics |or| git switch -c cpm-analytics 		to create branch cpm-analytics and switch to that new branch in 1 command

// =================== merge branch to master ==========================
1. go to master
git checkout master 
2. merger feature to master
git merge cpm-analytics 

// =================== delete new branch =======================
git branch -d cpm-analytics

// =================== or push an existing repository from local from the command line to GitHub ================
git remote add origin https://github.com/tranletramy/Git_tutorial.git
git branch -M main
git push -u origin main

// ========== Clone from github to local ==============================
git clone https://github.com/tranletramy/Git_tutorial.git

// ============= git fetch | git merge | git pull ================================
git fetch : download new info without changing your current files
git pull : download and merge the latest changes => does 2 things: fetch and merge
Note: to get the latest changes from GitHub, you must 1st run git fetch to contact GitHub for new changes, if not Git will not know if there is any changes on GitHub 
git merge origin/main 		merge GitHub changes into local branch

// ================ resolve merge conflict ===================
1. Open the conflicted file 
2. Decide what the final code should be, remove the conflict markers (<<<<<<<<<<, =========, >>>>>>>>>)
3. Save file
4. stage and commit the resolved file: 
   git add .
   git commit -m "resolve conflict"
   git push

// ======================= advance =========================
  ** commit partial file 
  git add -p  => press s during git add -p to split changes into smaller chunks 
  ** restore deleted file 
  git restore file.txt
  ** restore staged deleted file
  git restore --stage file.txt
  git restore file.txt
  ** restore deleted, staged and committed file
  git restore --source=HEAD~1 file.txt    or git restore --source=4152145 file.txt
  ** restore deleted, committed, and pushed file 
  git restore --source=4125122 file.txt

// =============== git cherry pick ====================
1. In master branch, create a file project.txt and commit
2. Checkout new branch 			git checkout -b branch-feature1
3. In branch, make 2 separate commits 
	commit 1: bugfix.txt
	commit 2: dashboard.txt
4. View history 			git log --oneline => copy the commit ID of commit fix bug
5. Switch to master 			git checkout master
6. Cherry-pick the bug fix 		git cherry-pick 142532
7. Verify 				git log --oneline

to move the things back to the previous status, example: if I committed file.txt, then
git reset --soft HEAD~1 	will move the file back to stage, not committed yet
